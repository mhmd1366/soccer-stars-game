# ⚽ فوتبال انگشتی (Soccer Stars — نسخه وب و موبایل)

یک بازی کامل، روان و کاملاً مستقل (Self-Contained) با الهام از **Soccer Stars**، پیاده‌سازی‌شده با **HTML5 Canvas**، **JavaScript خالص**، موتور فیزیک دوبعدی اختصاصی و صدای رویه‌ای (**Web Audio API**)؛ بدون نیاز به هیچ فایل تصویری یا صوتی خارجی و آماده انتشار فوری روی **GitHub Pages** یا تبدیل به اپلیکیشن اندروید (**APK**).

---

## ✨ ویژگی‌های کلیدی

- **گرافیک استادیومی باکیفیت:**
  - مهره‌های سه‌بعدی با حاشیه فلزی طلایی براق، بازتاب شیشه‌ای گنبدی، سایه نرم روی چمن و پرچم برداری ۱۲ کشور.
  - زمین چمن سبز شاداب دو رنگ با خطوط استاندارد، نورافکن استادیوم، تور مشبک متحرک و ۴ تیرک سه‌بعدی فیزیکی.
  - افکت‌های بصری (VFX): دنباله نورانی پشت توپ در شوت‌های پرقدرت، جرقه و موج ضربه در برخوردها، انفجار کونفتی و لرزش ملایم دوربین هنگام گل.
- **حالت‌های بازی:**
  - **تک‌نفره (1P vs AI):** رقابت با هوش مصنوعی در ۳ سطح **آسان**، **متوسط** و **حرفه‌ای** (دارای شوت بانکی از دیواره و دفاع جلوی دروازه).
  - **دونفره (2P Local - Pass & Play):** بازی نوبتی روی یک دستگاه با نوار زمان ۱۵ ثانیه‌ای برای هر حرکت.
- **انتخاب کشور و چینش تیم:**
  - ۱۲ تیم ملی محبوب: **ایران، آرژانتین، فرانسه، برزیل، آلمان، اسپانیا، پرتغال، انگلیس، ایتالیا، هلند، کرواسی و مراکش**.
  - ۳ چینش استاندارد: `1-2-2` (متعادل)، `1-3-1` (هجومی) و `2-2-1` (دفاعی).
- **موتور فیزیک دوبعدی اختصاصی:**
  - اجرای روان با `requestAnimationFrame`، `deltaTime` و تکنیک **Sub-stepping** (۸ زیرگام در هر فریم) برای جلوگیری از عبور توپ در سرعت‌های بالا.
  - برخورد کشسان واقعی میان مهره‌ها، توپ، دیواره‌ها و تیرک‌های دروازه.
- **صداگذاری و بازخورد لمسی:**
  - تولید تمام صداها (برخورد مهره، شوت توپ، برخورد تیرک، سوت داور و تشویق تماشاگران) با **Web Audio API** بدون فایل MP3.
  - پشتیبانی از بازخورد لرزشی موبایل (**Vibration API**) با قابلیت قطع و وصل در تنظیمات.

```text

├── index.html       # ساختار اصلی صفحه، متاتگ‌های موبایل و فونت Vazirmatn

    ├── flags.js     # رسم برداری پرچم ۱۲ کشور روی Canvas با کشینگ رتینا

    ├── physics.js   # موتور فیزیک دوبعدی با Sub-stepping و برخورد تیرک‌ها
    ├── ai.js        # هوش مصنوعی در ۳ سطح دشواری (آسان، متوسط، حرفه‌ای)
    └── game.js      # حلقه اصلی بازی، State Machine، VFX و رندرینگ
```

## 🚀 نحوه اجرا و انتشار در GitHub Pages

### ۱. اجرای محلی (Local)
کافی است فایل `index.html` را مستقیماً در مرورگر (Chrome، Firefox، Edge یا Safari) باز کنید. هیچ پیش‌نیازی برای نصب (`npm install`) وجود ندارد.

### ۲. انتشار رایگان روی GitHub Pages
1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `soccer-stars-game`).
2. تمام فایل‌ها و پوشه `js/` را در شاخه اصلی (`main`) آپلود کنید.
3. وارد مسیر **Settings → Pages** شوید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کرده و شاخه `main` و پوشه `/ (root)` را ذخیره کنید.
5. پس از حدود یک دقیقه، بازی شما در آدرس زیر در دسترس خواهد بود:
   ```text
   https://<نام-کاربری-شما>.github.io/<نام-ریپازیتوری>/
   ```

### ۳. تبدیل به اپلیکیشن اندروید (APK)
از آنجا که پروژه کاملاً بدون وابستگی خارجی (Self-Contained) است، می‌توانید به‌سادگی پوشه پروژه را در **Capacitor** (در پوشه `www/`) یا **Android WebView / TWA** قرار دهید و خروجی APK بگیرید.

## 🎮 نحوه بازی
- روی یکی از مهره‌های خودی کلیک یا لمس کنید و به سمت عقب بکشید (مانند تیرکمان).
- رنگ حلقه قدرت از **سبز** (ضربه آرام) به **زرد** و **قرمز** (شوت پرقدرت) تغییر می‌کند.
- برای **لغو شوت**، کافی است پیش از رها کردن، انگشت یا نشانگر موس را دوباره به مرکز مهره برگردانید.
- اولین تیمی که به تعداد گل انتخابی (۲، ۳ یا ۵ گل) برسد، برنده مسابقه است.
